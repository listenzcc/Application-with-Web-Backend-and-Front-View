# 软件安装使用说明书

## 1. 概述

本项目是一套基于 `NiceGUI` + `FastAPI` 的仿真展示与管理平台，提供：

- 传感器管理（`/sensors`）
- 气体管理与数据库（`/gasExplorer`）
- 化学品管理与数据库（`/chemicalExplorer`）
- 事故案例教育（`/accidents`，含伤亡散点图与气体分类饼图联动筛选）
- 仿真案例浏览（`/caseBrowser`）
- 扩散仿真：拉格朗日模型、追溯模型（主导航「扩散仿真(拉格朗日/追溯)」下拉）、高斯模型、CFD 三维模型（主导航「扩散仿真(CFD三维模型)」）
- 地图 / 室内动态播放页面（`/map` 系列与 `/room` 系列）
- 权限认证与用户管理（`/login`、`/register`、`/privilege`、`/profile`）

## 2. 软件环境

- 操作系统：
  - Windows（推荐）
    - Windows 11 专业版
    - 版本号 25H2
    - 安装日期 2025/2/15
    - 操作系统版本 26200.8037
    - 体验 Windows 功能体验包 1000.26100.300.0
  - Linux（可选）
    - 发行版：Ubuntu 22.04.5 LTS
- Python：>= 3.11（项目启动脚本 `serve-forever.ps1` 使用 conda 环境 `python3.11`）
- 推荐：Anaconda / Miniconda

## 3. 外部组件

除 Python 依赖外，数值计算还依赖两类本机组件，部署时需确认：

1. **数值仿真内核**：CFD 室内模型与城市扩散模型的求解器为独立的本机可执行程序，需按各模块配置中给定的路径安装；缺少内核时仿真任务会以失败标记退出，日志中给出缺失路径。
2. **气象数据目录**：扩散计算需要网格气象数据（默认查找 `D:/WeatherData/`，可在模块配置中调整）。当前随附样本数据覆盖 2024 年 5 月上旬，计算起始日期需落在数据覆盖范围内，否则任务失败并在日志提示「找不到气象文件」。

## 4. 依赖安装

Python 依赖清单在 `python/requirements.txt`：

- pandas
- loguru
- nicegui
- openpyxl
- werkzeug
- omegaconf
- pywebview
- sqlalchemy

安装命令：

```powershell
cd "<项目根目录>\python"
conda activate python3.11
pip install -r requirements.txt
```

## 5. 数据库初始化

业务数据库脚本位于项目根目录与 `python/` 下：

- 权限库：`init-auth-db.ps1`（对应 `python/init_auth_db.py`）
- 气体库：`init-gas-db.ps1`（对应 `python/init_gas_db.py`）
- 化学品库：`init-chemical-db.ps1`（对应 `python/init_chemical_db.py`）
- 传感器库：`init-sensors-db.ps1`（对应 `python/init_sensors_db.py`）

执行（任选 PowerShell 脚本或直接运行 Python 脚本）：

```powershell
cd "<项目根目录>"
.\init-auth-db.ps1
.\init-gas-db.ps1
.\init-chemical-db.ps1
.\init-sensors-db.ps1
```

初始化完成后 `db/` 下生成对应 SQLite 数据库文件。首次启动应用时若库不存在也会自动建表并写入默认数据（内置 `testuser`、`guest` 两个演示账号）。

城市监测点数据无需初始化：首次使用时按城市自动生成并缓存到 `data/stations/`。

辅助脚本：

- 室内仿真清理脚本：项目根目录提供的 PowerShell 清理脚本，可批量删除室内仿真的历史会话目录
- `keep-writing-sensors.ps1`：持续写入模拟传感器读数（演示用）

## 6. 启动方式

项目入口：`python/main.py`。可直接运行：

```powershell
cd "<项目根目录>"
conda activate python3.11
python python/main.py
```

或使用常驻启动脚本（内部即执行 `python python/main.py`）：

```powershell
.\serve-forever.ps1
```

启动后监听 `http://127.0.0.1:8080`（端口以启动日志为准），浏览器访问即进入登录页。

> 注意：修改 Python 或页面代码后需重启服务，页面不热重载。

## 8. 目录结构说明

```
<项目根目录>
├── python/            # 全部服务端代码（main.py、各仿真模块、auth、explorer 等）
├── static/
│   ├── html/          # 地图页与室内页模板（服务端注入参数后返回）
│   ├── src/           # 共享前端模块（等值线计算、三维渲染库本地化）
│   └── favicon/
├── conf/              # 项目元数据、模块配置、三维障碍物配色（YAML）
├── data/
│   ├── stations/      # 城市监测数据缓存
│   ├── gas/           # 气体库数据源
│   ├── chemical/      # 化学品库数据源
│   ├── accidents/     # 事故案例数据源
│   └── case/          # 仿真案例库
├── db/                # SQLite 业务数据库
├── <各仿真模块>/simulation/<会话>/   # 每次仿真一个自包含会话目录
└── serve-forever.ps1  # 常驻启动脚本
```

会话目录内含本次输入卡、参数存档 `config.json`、监测点存档、帧索引 `frames.json`、逐帧图像、运行日志与状态标记文件，可整目录拷贝迁移。

## 9. 维护与升级

- 修改代码后重启服务生效；退出按 `Ctrl+C` 或关闭常驻脚本窗口
- 日志：应用日志写入 `log/` 目录，仿真会话日志在各会话目录 `run.log`
- 清理：
  - 重置业务库：删除 `db/*` 后重新执行初始化脚本
  - 清理仿真历史：删除对应仿真模块 `simulation/` 下的会话目录（或使用清理脚本）
  - 清理监测缓存：删除 `data/stations/*`（下次访问自动重新生成）
- 升级：备份 `db/` 与 `data/` 后替换代码目录，数据库结构变更需重跑初始化脚本

## 10. 常见问题

| 现象 | 排查 |
| --- | --- |
| 页面打不开、全部 404 | 服务未启动或端口不对，看启动日志；确认浏览器访问地址与监听端口一致 |
| 访问任意页面都跳登录 | 鉴权中间件生效中，先登录；演示账号 `testuser` / `guest` |
| 仿真点「开始计算」后很快失败 | 打开会话目录 `run.log`：常见原因是找不到数值内核或气象数据不在覆盖范围 |
| 结果页空白 | 会话缺少 `success` 标记或帧索引损坏，查看 `run.log` 与 `frames.json` |
| 三维场景无画面 | 体数据帧与网格尺寸不符时前端会告警，确认输入卡的网格段未被手改坏 |
| 监测点数据想换一组 | 结果页或仿真页点「重新生成」；改时段则自动重算 |
