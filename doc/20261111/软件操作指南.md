# 软件操作指南

## 1. 登录与权限

- 访问 `/login` 登录；`/register` 注册新账号
- 首次运行自动创建内置演示账号（`testuser`、`guest`）
- 权限由 `auth/` 模块管理：
  - `user_service`：用户与角色服务
  - `PermissionManager`：功能权限点控制（如查看用户、创建用户、编辑删除）
  - `AuthContext`：当前登录上下文
- 未登录访问任何受保护页面都会被鉴权中间件重定向到登录页

## 2. 全局导航

登录后顶栏主导航（`components/layout.py`）：

- **扩散仿真(拉格朗日/追溯)**：下拉菜单，含「拉格朗日模型」「追溯模型」两项
- **扩散仿真(高斯模型)**：高斯模型独立入口
- **扩散仿真(CFD三维模型)**：室内三维仿真入口
- **仿真案例**：案例文件浏览与下载
- **气体管理**：气体数据库
- **化学品管理**：化学品数据库
- **权限管理**：用户与角色管理
- **传感器管理**：传感器列表与读数
- **事故教育**：事故案例检索与统计
- 右上角：个人资料（`/profile`）、退出登录

## 3. 首页 `/`

- 未登录显示：「立即登录」「了解更多」
- 已登录显示跳转按钮：仿真案例库、传感器管理、气体管理等
- 首页说明文本读取 `conf/project.yml` 的 `abstract` 字段，改配置即可更新

## 4. 仿真案例库 `/caseBrowser`

- 加载 `data/case` 下所有子目录，目录树浏览
- 支持文件预览（图片、PDF、文本）与文件下载
- 支持返回上级目录、按文件类型显示图标

## 5. 气体管理 `/gasExplorer`

- 创建 / 添加 / 删除气体记录
- 查询、排序、分页、统计（总量、毒性分布、分子量 / 沸点范围）
- 「编辑 / 删除」按钮受权限点控制，无权限时置灰
- 导出 Excel

## 6. 化学品管理 `/chemicalExplorer`

- 与气体管理同构的管理界面，数据源为 `data/chemical/`
- 支持新增、检索、详情查看与导出

## 7. 事故教育 `/accidents`

- 加载 `data/accidents/` 下的案例数据表
- 按「案例场景分类」下拉筛选 + 关键词搜索（案例名称、泄漏气体、位置、概要）
- 详情对话框展示完整案例信息，支持导出事故信息为 TXT
- 页面附两张统计图（伤亡人数散点图、泄漏气体分类饼图），跟随筛选条件实时联动

## 8. 传感器管理 `/sensors`

- 展示传感器列表（编号、位置）与最新读数
- 数据由传感器服务持续写入，页面定时刷新

## 9. 扩散仿真：城市监测点（三个扩散模型共用）

进入任一扩散模型页面，左侧上方为「城市与监测点」面板：

1. **城市下拉**：北京、上海、南京、武威、张掖五个预设城市；切换城市后地图中心、缩放、监测点全部跟随
2. **监测点表格**：列出站点名称、类型（厂区 / 厂界 / 敏感点）、最新读数、时段峰值
3. **读数时序图**：各站点逐小时读数曲线（ECharts），模拟日期 / 时长输入变化时横轴自动跟随
4. **重新生成按钮**：不改变时段的前提下换一组监测读数（确定性生成，同参数结果一致）

释放强度自动按站点峰值读数折算，无需手动填释放速率。

## 10. 扩散仿真操作步骤

### 拉格朗日模型 / 高斯模型

1. 选择城市，确认监测点表格与时序图正常
2. 填写模拟日期（年 / 月 / 日）、起始时刻、扩散时长
3. 可选：手动指定危险区三级阈值（轻伤 / 重伤 / 致死），留空则按本次量程自动取
4. 点击「开始拉格朗日模型计算」（或「开始高斯模型计算」）
5. 计算在后台进行，完成后嵌入窗口自动切换到结果地图页

### 追溯模型

操作与上面一致，额外说明：

- 扩散时长填**负数**表示向前追溯（如 `-12` 表示向前追溯 12 小时）
- 结果帧的时间标签是真实的过去时刻

### 结果页（地图）操作

- 底部 HUD：播放 / 暂停按钮 + 可拖拽时间轴，逐帧播放烟羽
- **危险区三级等值线**：轻伤区（橙）、重伤区（深橙红）、致死区（深红）三层套叠；阈值可在 HUD 直接修改，回车即重画，无需重算
- 监测点标记：颜色随读数从绿到红渐变，悬停显示名称与读数
- 图例显示本次量程与色标；历史下拉切换会话时，地图自动平移到该会话监测点中心

## 11. CFD 三维模型操作

1. **输入卡编辑**：页面主体是大编辑器，可直接修改输入卡文本；右侧障碍物表格与编辑器双向联动（表格改动即改写输入卡对应段，反之亦然）
2. **参数校验**：保存时自动校验网格段、计算时长、输出帧数，错误会以提示框给出具体原因
3. **开始计算**：点击「开始三维 CFD 计算」，后台运行，完成后进入三维结果页
4. **三维结果页**：
   - 鼠标左键旋转、右键平移、滚轮缩放
   - 障碍物按名称配色显示（配色来自 `conf/` 下的 YAML 配置，改完刷新页面即生效）
   - 体渲染烟羽：「云浓度」滑杆调整体不透明度，「采样步长」调节光线步进密度（画面质量与流畅度折中）
   - **危险区三级着色**：与扩散模型一致的三级阈值，HUD 实时调整即时生效
   - **检测点波形面板**：点「检测点波形」按钮，按单位分组展示各检测点时序，虚线联动当前帧时间
   - **时间轴档位**：时间轴旁的下拉可选每格跨 5 / 10 / 30 / 60 秒（模拟时间），拖动时按档位吸附跳帧；长时段数据建议用大档位快速定位，再切回 5 秒档细看

## 12. 用户与权限管理 `/privilege`

- 查看当前登录用户信息
- 用户列表（需 `view_users` 权限）：编辑、删除用户
- 新建用户：指定角色（guest / user）与初始密码
- 注销登录：`/profile` 页面右上角按钮

## 13. 调试与日志

- 应用日志在 `log/` 目录；每次仿真的完整日志在对应会话目录 `run.log`
- 会话状态以 `success` / `failed` 标记文件为准：页面轮询据此显示「运行中 / 已完成 / 失败」
- 失败排查顺序：`run.log` 报错行 → 会话目录输入卡与 `config.json` → 气象数据覆盖范围 → 数值内核路径
- 浏览器端可用 DevTool 查看 console 与网络请求（结果接口、帧图片加载）

## 14. 安全与退出

- 登出：`/profile` 页「Logout」按钮，会话立即失效
- 生产环境建议：开启 HTTPS、固定 `storage_secret`、关闭热重载、按角色收紧权限点
- 演示账号（`testuser`、`guest`）仅用于交付演示，正式部署前应删除或改密
