# 搭建仿真动态显示系统说明书

## 1. 系统目标

本系统是一套基于 Web 的泄漏扩散仿真动态展示平台，面向化工园区风险评估与应急处置场景，集成：

- **城市监测点体系**：内置 5 个城市（北京、上海、南京、武威、张掖）预设，每个城市 6～8 个监测点（厂区、厂界、敏感点三类），监测读数按「城市 + 站点 + 时段」确定性生成并缓存，时段调整自动重算。
- **四套数值仿真模块**：拉格朗日扩散模型、高斯扩散模型、向前追溯模型、CFD 三维室内模型。各模型独立运行、互不干扰，界面与操作保持一致。
- **地图与场景动态渲染**：烟羽云图随时间轴逐帧播放，危险区按「轻伤 / 重伤 / 致死」三级等值线标注，监测点位置与读数实时映射到地图。
- **三维室内可视化**：体渲染烟羽、障碍物按名称配色、检测点波形面板、时间轴多档位拖动。
- **实时与历史会话切换**：每次计算落盘为一个自包含会话目录，历史结果可随时回看，回看时地图自动定位到监测点中心。
- **配套业务功能**：气体管理、化学品管理、事故案例教育、仿真案例库、用户权限体系。

## 2. 总体架构

系统自上而下分四层：

| 层次 | 内容 | 说明 |
| --- | --- | --- |
| 前端展示层 | `static/html/` 下的地图页与场景页模板、`static/src/` 共享 JS | 纯静态模板 + Mapbox GL / Three.js / ECharts，由服务端注入参数后返回 |
| 服务路由层 | `python/main.py` | NiceGUI 页面路由 + FastAPI 接口 + 参数注入 + 鉴权中间件 |
| 仿真计算层 | 各仿真模块的 `simulate.py` 与辅助脚本 | 每次计算起独立后台进程，通过 `success` / `failed` 标记文件汇报状态 |
| 数据与存储层 | 会话目录、`db/`、`data/`、`conf/` | SQLite 业务库 + 文件系统会话归档 + YAML 配置 |

页面由 FastAPI 读取模板文件后做字符串替换注入参数（会话号、经纬度、城市等），不依赖服务端模板引擎；前端渲染全部在浏览器完成。

## 3. 代码模块概览

- `python/main.py`：主 UI + 全部页面路由 + 仿真入口 + 结果查询接口
- **城市扩散仿真模块**（拉格朗日 / 高斯 / 追溯三套，目录结构一致）：
  - `simulate.py`：仿真核心（会话管理、参数合并、调度后台进程、结果收集）
  - `stations.py`：城市监测点预设与监测数据生成（三套模型共用）
  - `mk_control.py` / `mk_images.py`：输入卡构造与帧图导出
- **CFD 室内仿真模块**：
  - `simulate.py`：输入卡解析（几何、网格、检测点）、仿真调度
  - 三维体数据管线：体数据逐帧导出与压缩（uint8 体素文件 + 帧索引）
- `python/components/layout.py`：全站主题（深蓝底白字）与主导航布局
- `python/auth/`：权限认证与用户控制（登录、会话、角色、权限点）
- `python/explorer/`：气体、化学品、传感器等实体的管理界面与数据库
- `python/accidents_stats.py`：事故案例统计图表（伤亡散点、气体分类饼图）
- `static/html/`：`map.html`（地图页，拉格朗日 / 高斯 / 追溯各一份镜像）、`room.html`（室内平面页）、`room3d.html`（三维体渲染页）
- `static/src/contour.js`：危险区等值线共享计算模块（marching squares + 平滑 + 掩膜），地图页与室内页共用
- `conf/`：项目元数据与三维模型障碍物配色（YAML，按障碍物名映射颜色，改完刷新页面即生效）
- `data/stations/`：城市监测数据缓存；`data/gas/`、`data/chemical/`、`data/accidents/`、`data/case/`：业务数据源

## 4. 城市监测点子系统

监测点体系与业务传感器库完全解耦，专供扩散仿真使用：

1. **预设**：5 个城市，每城 6～8 个站点，用相对市中心的公里偏移换算成真实经纬度；站点分厂区、厂界、敏感点三类，带语义化名称（储罐区北、装卸车台、下风向 3 km 等）。
2. **数据生成**：按「城市 + 站点 + 时段」确定性生成逐小时时序——基线噪声 + 泄漏点附近站点的高斯抬升，影响幅度随距离指数衰减；结果缓存到 `data/stations/<城市>.json`，时段变更自动重算，点「重新生成」才更换一组。
3. **释放强度折算**：以站点时段内峰值读数折算污染物释放速率，避免起始时刻读数为零导致无有效释放。
4. **接口**：`/get_city_stations` 提供指定城市的监测点与读数，供地图页在未选择会话时预览点位。

## 5. 仿真调用流程

三套城市扩散模型的调用流程一致：

1. 进入对应仿真页面，左侧为「城市与监测点」面板 + 地理气象设置 + 计算设置；
2. 城市下拉切换后，监测点表格、读数时序图（ECharts）、地图预览点位同步刷新；模拟日期 / 时长变化时，监测数据横轴跟随变化；
3. 点击「开始计算」，后端合并界面参数与默认值（城市、计算域 bbox、起始时刻、时长、三级危险区阈值等）写入会话 `config.json`，起后台进程执行计算，立即返回会话号；
4. 前端轮询会话状态（读 `success` / `failed` 标记文件），完成后自动把嵌入 iframe 切到该会话的结果页；
5. 历史下拉列出全部会话，切换即回看；地图自动平移到该会话监测点的经纬度均值，同一会话只定位一次，轮询重绘不抢镜头。

CFD 三维模型的流程差异：页面主体是大输入卡编辑器 + 障碍物表格双向联动（编辑表格即改写输入卡对应段），保存后校验网格 / 时长 / 帧数，通过后落盘原输入卡并起计算；结果页为三维体渲染场景。

## 6. 地图与场景动态显示

### 地图页入口

- 服务端读取 `static/html/map.html`（高斯 / 追溯各有一份同构镜像），注入 `{{zoom}}`、`{{lat}}`、`{{lon}}`、`{{city}}`、`{{session}}` 后返回；
- 页面加载后请求结果接口，取 `frames.json` 作为时间轴唯一数据源（帧列表、帧数、量程上下限）；
- 烟羽用 canvas 源渲染（会话级固定网格 + viridis 色带 + 透明度按浓度幂次放大 + 双线性平滑），三级危险区等值线由共享模块 `contour.js` 计算（散点还原规则网格 → 外圈补边 → 平滑 → marching squares → Chaikin 平滑折线）。

### 室内页入口

- `room.html`（平面帧播放）与 `room3d.html`（三维体渲染）同理注入 `{{session}}`；
- 三维场景：体数据以三维纹理 + 光线步进着色渲染，障碍物按配色配置着色，检测点以蓝点标注；波形面板按单位分组展示检测点时序，与当前帧时间虚线联动。

### iframe 嵌入

各仿真页面通过 `<iframe id="map-iframe">` 嵌入结果页，切换会话或城市时由 JS 动态改写 `src`（携带会话号、中心坐标、缩放、城市参数）。

## 7. 危险区三级阈值

- 三级分别为**轻伤区**（橙色）、**重伤区**（深橙红）、**致死区**（深红），从外到里逐层套叠；
- 阈值是「看结果」的参数，不参与仿真计算本身：留空时按本次量程自动取 35% / 47.5% / 60% 处，也可在结果页 HUD 或仿真页表单里手动指定（存档进 `config.json`）；
- HUD 修改阈值立即重画等值线，无需重算；图例同步显示每级「≥ 阈值 · 块数」。

## 8. 仿真结果获取接口

每套仿真模块提供同构的查询接口（按模块前缀区分，结构一致）：

| 接口类型 | 返回 | 说明 |
| --- | --- | --- |
| 结果总览 | JSON | `config`（本次参数存档）、`environment`（计算域、城市中心、释放点、监测点列表）、`frames`（帧索引与量程）、状态 |
| 帧图像 | PNG | 指定会话 + 帧号的烟羽图；三维模块另提供体数据字节流 |
| 浓度表格 | JSON | 各帧网格点经纬度与浓度值（仅保留绘图所需列，控制前端内存） |
| 模板查看 | 文本 | 本次实际使用的输入卡 / 控制文件 |
| 城市监测点 | JSON | 指定城市的站点列表与读数（地图预览用） |

结果总览里的 `environment.stations` 携带每个监测点的名称、类型、经纬度与读数，地图页据此画站点标记（颜色随读数从绿到红渐变）。

## 9. 会话目录文件结构

每次仿真落盘为一个自包含会话目录，命名 `年-月-日-时-分-秒-<uuid>`，包含：

- **输入卡**：本次计算的真实输入（扩散模型为控制文件，CFD 为模板卡），保证结果可复现；
- `config.json`：界面参数与派生参数存档（含城市、计算域、三级阈值）；
- `stations.json`：本次使用的监测点与读数（旧会话兼容旧传感器格式）；
- `frames.json`：时间轴数据源（帧列表、帧数、量程）；
- `img/`（三维为 `volume/`）：逐帧 PNG 或体素数据；
- `run.log`：运行日志；
- `success` / `failed` 标记文件：状态判定唯一依据，不看图片是否生成。

## 10. 部署建议

- 使用 `uvicorn` 生产启动（去掉热重载）：

```bash
uvicorn python.main:app --host 0.0.0.0 --port 8000 --workers 4
```

- **外部组件**：CFD 与扩散计算依赖本机安装的数值仿真内核（需单独部署，路径写入各模块配置）；扩散计算还需要气象数据目录（默认 `D:/WeatherData/`，当前样本数据覆盖 2024 年 5 月上旬，计算日期需落在数据覆盖范围内）；
- 数据目录：生产环境建议把各仿真会话目录、`db/`、`data/` 挂独立存储卷，与代码分离；
- 定期清理历史会话（提供清理脚本，按会话目录批量删除）；
- 生产强制 HTTPS；鉴权中间件已保护全部非白名单页面，白名单仅登录 / 注册 / 欢迎页。

## 11. 关键点校验

- 登录成功后写入认证状态，`EnhancedAuthMiddleware` 拦截未登录访问；
- 会话由 cookie 承载，`session_manager` 统一管理活动超时；
- 地图页 / 场景页以会话号为唯一索引，参数注入后 iframe 与页面状态同步；
- 各仿真模块的调度入口为「合并参数 → 落盘会话 → 后台进程 → 标记文件汇报」四步，结果接口只读会话目录；
- 城市监测点模块与业务传感器库无耦合，删除或重置传感器库不影响扩散仿真。

## 12. 拓展建议

1. WebSocket 实时帧推送：替代轮询，缩短计算完成到画面刷新的延迟；
2. 定时任务触发：按周期读取监测数据，超阈值自动触发一次扩散计算；
3. 仿真进度指示：解析运行日志输出百分比进度条；
4. 失败回滚与重试：会话失败时保留日志并支持一键重跑；
5. 前端图层在线开关：烟羽、风场、管廊、行政边界分层控制；
6. 监测数据接入真实源：城市监测点预留数据替换接口，可由真实站网数据替换确定性生成数据。
